# Changelog

All notable changes to Essence Radio will be documented in this file.

## [1.0.0] - 2024-01-XX

### Added
- Initial project setup with monorepo structure
- NestJS backend with JWT authentication
- React web application with WebRTC support
- Expo React Native mobile application
- Docker configuration for one-click deployment
- MySQL database with TypeORM
- WebSocket chat functionality
- WebRTC audio streaming (publisher/listener)
- Admin panel for station and user management
- Station CRUD operations
- Real-time chat with Socket.IO
- User authentication and authorization

### Features
- User registration and login
- Station creation and management
- Live audio streaming via WebRTC
- Real-time chat
- Admin dashboard
- Mobile app support (iOS/Android)

### Technical Stack
- Backend: NestJS, TypeORM, MySQL, Socket.IO
- Web: React, Vite, TypeScript
- Mobile: React Native, Expo
- Deployment: Docker, Docker Compose
